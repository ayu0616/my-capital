# Asset & Life Studio

金融資産・持株会・カメラ機材・自己投資をまとめて管理する、個人用の資産ダッシュボードです。

- **金融資産**: 楽天銀行・三井住友銀行ごとの現預金、純資産（機材込み）、NISA目標額までの進捗、必要な月額積立、ポートフォリオ比率
- **楽天証券CSV**: 「保有商品一覧（すべて）」を取り込み、投資信託・個別株・その他の証券・預り金を月次記録へ反映
- **優待株**: JR西日本株を100株集めるなどの株主優待目標を登録し、現在株数・期限・1株単位の購入ペース・必要月額を管理。CSV取り込みで現在株数を自動更新
- **確定拠出年金**: 会社型DC「JIS&T」の評価額・累計拠出額・本人/会社の月額拠出・商品配分を管理。純資産と月次推移に反映
- **持株会**: 会社ページの記録日・持分株数・平均取得単価・繰越金、富士通株の保有数と目標株数までの進捗、SMBC日興証券への引出し履歴、奨励金込みの実質単価、到達後のリバランス提案。富士通の株価はGoogle Financeから日次で自動取得し、設定画面から再取得できます
- **口座管理**: 楽天証券・SMBC日興証券・楽天銀行・SMBCの役割を整理し、持株会の引出し先やCSV取り込み先を明確化
- **実物資産**: カメラ機材の購入額・買取目安・残存率、R2 に保存する機材写真
- **自己投資**: 資格・講座・書籍への投資履歴と、キャリアイベントによる ROI
- **毎月の記録**: 12か月の資産推移、配分のドーナツチャート、スナップショットの作成・編集・削除

## ローカル起動

```bash
npm install
npm run db:migrate   # ローカル D1 にマイグレーションを適用
npm run db:seed      # 任意: デモデータを投入
npm run dev          # http://localhost:3000
```

### 楽天証券のCSV取り込み

1. 楽天証券にログインし、「保有商品一覧（すべて）」をCSVで保存します。
2. `/assets` の「楽天証券の保有銘柄」から「CSVを取り込む」を選びます。
3. 基準日を確認し、必要なら「NISA累計元本をCSVの取得額に合わせる」をオンにして取り込みます。

- UTF-8とShift_JISの両方に対応しています。CSVはブラウザで解析し、保有銘柄と集計値だけをD1に保存します。
- 投資信託・個別株・その他の証券・預り金を、基準日の月のスナップショットへ反映します。銀行の現預金、持株会、機材の値は変更しません。
- 銘柄コードが一致する優待株の目標がある場合、現在株数・株価・平均取得単価もCSVの値に更新します（取り込み時にオフ也可）。
- 富士通（6702）はロマン枠として分離し、それ以外の個別株は「個別株」に集計します。
- 動作確認用に `seeds/rakuten-holdings-sample.csv` を同梱しています。

### パスコード / パスキー認証（任意）

公開時は `APP_PASSCODE` を設定するか、設定画面からパスキーを登録すると、ログイン画面なしでは台帳を開けなくなります。

```bash
# ローカル
cp .dev.vars.example .dev.vars
# .dev.vars の APP_PASSCODE を変更してから npm run dev

# 本番
npx wrangler secret put APP_PASSCODE
```

- `APP_PASSCODE` を設定すると、パスコードでログインできます。パスコードは推測されにくい12文字以上を推奨します。
- 設定 → パスキーから端末の生体認証やPINを使うパスキーを追加できます。パスキーだけを登録した場合もログイン必須になります。
- パスキーは WebAuthn の資格情報として D1 に保存します。パスキーはオリジンごとなので、ローカルの `localhost` で登録したものは本番ドメインでは使えません。
- セッションは HMAC 署名付きの HttpOnly Cookie として30日間保持されます。署名鍵は D1 に保存した秘密と `APP_PASSCODE` から PBKDF2 で導出するため、パスコードを変更すると既存セッションは無効になります。
- パスコードもパスキーも使えなくなった場合は、`npx wrangler secret put APP_PASSCODE` で新しいパスコードを設定してログインし、設定画面からパスキーを整理してください。
- どちらも設定していない場合は認証が無効になり、これまでどおりオープンアクセスで動作します。
- 画像配信 API とアップロード API も、認証が有効なときは同じセッションを要求します。

## Cloudflare へのデプロイ

```bash
npx wrangler login

# 1. D1 を作成し、表示された database_id を wrangler.jsonc に貼り付ける
npx wrangler d1 create my-capital-db

# 2. R2 バケットを作成
npx wrangler r2 bucket create my-capital-gear

# 3. 本番 D1 にマイグレーションを適用
npm run db:migrate:remote

# 4. 必要ならデモデータを投入（本番では通常不要）
# npm run db:seed:remote

# 5. パスコードを設定してデプロイ
npx wrangler secret put APP_PASSCODE
npm run deploy
```

`wrangler.jsonc` の `database_id` はプレースホルダーのままなので、デプロイ前に必ず置き換えてください。

## 計算の前提

- **純資産（機材込み）** = 銀行の現預金（楽天銀行＋三井住友銀行） + 証券口座の預り金 + 投資信託 + 個別株 + その他の証券 + 確定拠出年金 + 持株会・引出し済み・ロマン枠の評価額 + 持株会の繰越金 + 機材の買取目安
- **NISA 進捗** は累計元本ベース。目標額と目標年齢から、達成に必要な月額を逆算します。
- **持株会** は月次拠出額と奨励金率から月あたりの獲得株数を算出し、目標株数までの残月数を表示します。会社ページの平均取得単価から取得原価・評価損益も計算します。引出しを記録すると持株会の現在株数を減らし、SMBC日興証券側の株数として履歴に残します。富士通の株価はGoogle Finance（取得できない場合はYahoo Finance）から1日1回自動取得し、当日の株価を記録済みなら再取得しません。
- **優待株** は目標株数までの残り株数を期限までの月数で割り、月あたりの必要株数と必要月額を計算します。月の購入予算を入れると、現在株価から到達月を逆算します。1株単位・100株単位のどちらにも対応し、手数料・税金・株価変動は含みません。
- **確定拠出年金（JIS&T）** は評価額を純資産とポートフォリオに含めます。累計拠出額との差を評価損益として表示し、商品配分は評価額に対する比率で管理します。評価額を保存すると、最新月のスナップショットにも同じ金額を反映します。
- **富士通比率** が設定した警告ライン（初期値15%）を超えると、ダッシュボードに警告が出ます。
- **投資 ROI** = キャリアイベントによる年収増加額の合計 ÷ 自己投資コスト。税・手取りは考慮しません。

## データモデル

D1 のテーブルはすべて単一ユーザー前提のシングルトン、または履歴テーブルです。将来のマルチテナント化を見据えて、各テーブルには `user_id` を追加できる形にしています。

- `app_settings` — ニックネーム、生年月日、NISA 目標、警告ライン、レンズ積立
- `auth_passkeys` — パスキーの資格情報（credential ID・公開鍵・カウンタ・名前）
- `auth_config` — セッション署名に使うサーバー側の秘密
- `auth_challenges` — WebAuthn の登録・ログイン用チャレンジ（検証時に消費）
- `holding_stock_status` — 持株会の拠出額・奨励金率・保有株数・記録日・平均取得単価・繰越金
- `holding_withdrawals` — 持株会から証券口座へ引き出した日付・株数・取得単価・株価・引出し先
- `stock_goals` — 優待株の目標株数・期限・現在株数・最小購入単位・月予算・優待内容
- `retirement_accounts` — JIS&Tの評価額・累計拠出額・本人/会社の月額拠出・基準日
- `retirement_allocations` — JIS&Tの商品配分（商品名と比率）
- `financial_accounts` — 楽天証券・SMBC日興証券・楽天銀行・SMBC・JIS&Tなどの口座メタデータ
- `securities_import_batches` — 楽天証券CSVの取り込み単位（基準日・ファイル名・集計値）
- `securities_holdings` — CSVから取り込んだ保有銘柄（種別・口座・数量・評価額・取得額）
- `asset_snapshots` — 月次の資産スナップショット（互換用の派生キャッシュ。正の記録は `asset_entries`）
- `asset_entries` — 項目ごとの評価額台帳（評価日・項目キー・値）。月次スナップショットはここから繰越集計する
- `camera_gears` — 機材台帳（R2 の画像キーを含む）
- `self_investments` — 資格・講座・書籍の記録
- `career_events` — 昇格・昇給などのキャリアイベント
